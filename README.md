# Sass Dashboard - AI Freelancer Tools 🚀

A modern, high-performance platform for freelancers to manage clients, track projects, generate AI-powered proposals, and handle invoicing.

## Tech Architecture

### Frontend
- **Next.js (App Router)**: Modern React framework.
- **Tailwind CSS**: Utility-first CSS for styling.
- **Framer Motion**: Smooth animations and transitions.
- **Lucide React**: Beautiful icons.

### Backend
- **Java (Spring Boot)**: Robust and scalable REST API.
- **PostgreSQL**: Reliable relational database.
- **Lombok**: Reduced boilerplate code.
- **Spring Data JPA**: Efficient database access.

## Setup

### Frontend
```bash
npm install
npm run dev
```

### Backend
1. Ensure Java 21+ is installed.
2. Configure your PostgreSQL in `backend/src/main/resources/application.properties`.
3. Run with Maven: `./mvnw spring-boot:run` (once wrapper is added).
